# Чтобы раскатить сервис необходимо:
1. Сгенерировать на сервере, c которого будет запускаться ansible-плейбук, ssh-ключ с помощью команды `ssh-keygen`
2. Отправить публичный ssh-ключ на сервер, на который будет воздействовать ansible-плейбук с помощью команды `ssh-copy-id [имя пользователя сервера, на который будет воздействовать ansible-плейбук]@[ip-адрес сервера, на который будет воздействовать ansible-плейбук]`
3. Убедиться, что на сервере, на который будет воздействовать ansible-плейбук, установлен python с помощью команды `pip3 --version`, если его нет, установить python с помощью `sudo dnf install python3-pip`
4. Убедиться, что на сервере, c которого будет запускаться ansible-плейбук, прикрепленные файлы расположены следующим образом:
   - kasp_main.yml
   - roles/observed/tasks/main.yml
   - roles/observed/files/Dockerfile
   - roles/observed/files/prometheus_server.py
   - roles/observed/templates/prometheus_server_service.j2
5. **(Для раскатки не через контейнер)** на сервере, с которого будет запускаться ansible-плейбук, ввести команду: 
`ansible-playbook -i '[имя пользователя сервера, на который будет воздействовать ansible-плейбук]@[ip-адрес сервера, на который будет воздействовать ansible-плейбук]', --private-key [путь к ssh-ключу сервера, с которого запускается ansible-плейбук] kasp_main.yml`  
*(Если прописать инвентарь и конфиг-файл, а в конфиг-файле обозначить инвентарь и ssh-ключ, прописывать их в команде будет не нужно, и достаточно будет `ansible-playbook kasp_main.yml`)*

# Чтобы собрать docker-образ:
Docker-образ собирается автоматически при запуске ansible-плейбука, для этого необходимо добавить --extra-vars "deployment_method=container" в вышеописанную команду: 
`ansible-playbook -i '[имя пользователя сервера, на который будет воздействовать ansible-плейбук]@[ip-адрес сервера, на который будет воздействовать ansible-плейбук]', --private-key [путь к ssh-ключу сервера, с которого запускается ansible-плейбук] --extra-vars "deployment_method=container" kasp_main.yml`  
*(Также перед выполнением данной команды необходимо установить Docker)*

# Чтобы создать виртуальную машину:
1. Ввести недостающие значения переменных в vars.tfvars в формате:
```
yc_token  = [яндекс токен пользователя]  
yc_cloud_id  = [id Yandex Cloud]  
yc_folder_id = [id каталога в Yandex Cloud]
```
2. Заменить прописанные пути к ssh-ключу в main.tf в строчках `ssh-keys = "almalinux:${file("~/.ssh/main-kl-try.pub")}"` и `private_key = file("~/.ssh/main-kl-try")`
3. Запустить terraform с помощью команды `terraform apply -var-file vars.tfvars`  
*(В данном случае генерацию и проброс ssh-ключей, а также проверку зависимостей из предыдущих разделов можно опустить)*
